01The problem

You already know the hard part.

Whether you train models, ship AI features or analyse data, the central problems of securing AI agents have statistical twins in your own toolbox. The course supplies the security half.

01

Rare events

Attacks are rare. How often an alert is right is set by the base rate, not by how good the detector looks on a balanced test set.

02

Operating points

Every threshold spends a false-alarm budget. You choose where to spend it, and measure it where the system acts.

03

Distribution shift

A detector tested on prose meets JSON, logs, diffs and SQL in production, and behaves differently.

04

Counterfactuals

Will a new policy help? Replay it over last month's traffic and run it in shadow before you enforce it.

04Scale

Build it small. Reason about it at scale.

Every module of the course, and the workshop in half a day, runs the same two steps: build and measure it locally, then work out what it becomes at scale. A 1% false-alarm rate is a rounding error on a laptop, and an organisation at fifty million calls a day.

Locally: build and measure
101alerts

You attack an agent, defend it and measure it yourself: 10,000 calls, one real attack, 101 alerts. Every number is one you produced and can explain.

At 50 million calls a day: work it out
500,000false alarms

The same 1% error rate. At 30 seconds each, that is about 520 analysts, working full time, just to clear the false ones. You get there by calculation from your own measurements.

07Questions

Frequently asked.

Why this course?

We reviewed the 26 university courses on machine-learning, LLM and agent security whose schedules are public. None teaches runtime enforcement, evidence or operations for AI agents as a subject. This course is built around them, and around evaluation at production scale.

Do I need a security background?

No. The course assumes Python and the basics of statistics or machine learning, and teaches the security from the ground up. A free four-hour on-ramp covers the web plumbing.

What do I need to run it?

A laptop with 8 GB of memory, running macOS, Windows (with WSL 2) or Linux. No GPU is required. Installing Docker and setting up the lab is a module of its own.

Which products does it teach?

None. You build every component yourself with open, general-purpose tools, and wherever a tool is chosen the lesson names an alternative.

Is it really free?

Yes. Every lesson, build and automated check is free. Only the final exam, which a person reviews, and the certificate that follows are paid.

In which languages?

English and Hebrew. Code, commands and tools stay in English in both.

When does it open?
