01What you will learn

Turn your ML skills into security decisions.

You already work with models, data and uncertainty. Learn to apply that experience to a new set of questions: which actions need protection, which alerts deserve attention and what evidence is enough to trust a defence.

01

Decide which alerts matter

Use base rates to work out how many alerts are real attacks, and how much investigation your team can handle.

02

Choose a workable threshold

Balance attacks caught against legitimate work blocked. Set thresholds against an explicit false-alarm budget.

03

Test on the data agents use

Evaluate on documents, tool calls, JSON and logs. Find out what changes when production data differs from your test set.

04

Evaluate a policy before rollout

Replay recorded traffic and test in shadow mode to assess a policy before it starts blocking actions.

03What you will build

A working security layer for an AI agent.

Start with a small agent and build the controls around it: detection, enforcement, evaluation and incident response. Use open, general-purpose tools so you can inspect the code, change it and explain each decision.

  1. M01A tool-calling agent and an attack you can reproduce
  2. M03A gateway that checks tool calls before they run
  3. M04Prompt-injection detectors using patterns and a trained classifier
  4. M08An evaluation harness to measure attacks caught and legitimate tasks blocked
  5. M11Controls that track untrusted data and restrict what it can influence
  6. M12Scoped credentials, a sandbox and a kill switch
  7. M16A signed audit log and replay tools to investigate decisions
  8. M18An incident response runbook tested against a recorded attack
04From lab to production

A small error rate can become a full-time job.

Build and measure locally, then calculate what your results imply at higher volumes. Learn to account for review time, false alarms and capacity before deciding whether a control is practical to operate.

An illustrative workload
101alerts from 10,000 calls

With one attack per 10,000 calls, a detector that catches 99% of attacks and flags 1% of harmless calls produces about 101 alerts. Only about one corresponds to a real attack.

At 50 million calls a day
500,000false alarms per day, approximately

At the same attack frequency and false-alarm rate, reviewing each false alert for 30 seconds would take about 520 eight-hour workdays, every day. Use this calculation to set an operational budget.

07Before you join

Frequently asked questions.

Who is this course for?

Developers, ML and applied AI engineers, data scientists and analysts who connect models to data and tools. It focuses on building and evaluating controls, from a tool call to incident response.

Do I need a security background?

No. You need Python and the basics of statistics or machine learning. Security concepts are taught from the ground up, and a free four-hour preparation module covers web fundamentals.

What equipment do I need?

A laptop with at least 8 GB of memory running macOS, Linux or Windows with WSL 2. No GPU is required. A dedicated module walks you through Docker and lab setup.

Does it teach a particular security product?

You build the components with open, general-purpose tools. The lessons explain the choices and name alternatives, so you can understand the approach and adapt it to your own stack.

What is free, and what is paid?

All lessons, labs and automated checks will be free. Only the optional final assessment and certificate are paid. You can complete the learning material without paying for assessment.

What languages are available?

English and Hebrew. Code, commands and tool names stay in English in both versions.

When can I start?

The course is in preparation. Join the waitlist to hear when the first modules are published. There is no launch date to announce yet.

Can my team get started sooner?

The live workshop is available separately: a four-hour session for up to 15 people, at your office or on Zoom. It covers an attack, defences and evaluation, and does not require the course.
