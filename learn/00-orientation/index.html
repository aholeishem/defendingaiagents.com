Orientation: why agent security is a statistics problem

Statistical twin The whole course. This module makes the claim the rest of it proves.

A language model that only talks can embarrass you. A language model that calls tools can spend your money, mail your customer list and push to your main branch. This module says what an agent is, where the security boundary goes, and why most of the hard problems on that boundary are ones you already know from statistics.

  • Classify a control as by design or by detection, and name what each would miss. <span class="label tier">Foundations</span>
  • Compute an alert stream's precision from recall, FPR and base rate, and correct a calibrated score for a deployment prior. <span class="label tier">Advanced</span>
  • Bound an FPR from zero observed false positives, size the benign sample a target FPR needs, and estimate a deployment FPR from a labelled stratum. <span class="label tier">Advanced</span>
  • Compute the effective recall of a detector whose alerts exceed review capacity. <span class="label tier">Advanced</span>
  • Separate what last month's log can and cannot estimate about a proposed policy change, and say what logging would answer the rest. <span class="label tier">Advanced</span>
  • Derive a hold threshold from the costs of each error and the base rate, and turn it into a raw-score threshold. <span class="label tier">Expert</span>
  • Label an agent's sources and sinks on an integrity and confidentiality lattice and state the flow policy that blocks a given harm; find an implicit flow that copies no value, count the bits it leaks, and say why noninterference is proved from structure, not estimated from samples. <span class="label tier">Expert</span>
  • Specify an adaptive evaluation of a detector (knowledge, budget, method, success criterion, interval) and state when you would refuse to publish its number. <span class="label tier">Expert</span>

  • Wallace, E. et al. "The instruction hierarchy: training LLMs to prioritize privileged instructions." arXiv:2404.13208, 2024.
  • Nasr, M. et al. "The attacker moves second: stronger adaptive attacks bypass defenses against LLM jailbreaks and prompt injections." arXiv:2510.09023, 2025.
